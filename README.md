# Hello❤
![alt text](screenshot.png "screenshot")

A tiny music intro for Commodore 64, executable prg is 508 bytes so exactly two disk blocks.

Originally done over a year ago but I rewrote it to fit to the rules of the Zooparty two block compo. This will not go to the actual compo though.

Also included is a sid-version and separate sid source that could be useful to see how to hand craft a sid file directly from vasm.

Tools used:  
Vasm: http://sun.hasenbraten.de/vasm/  
Retrodebugger: https://github.com/slajerek/RetroDebugger  
VSCodium: https://github.com/VSCodium/vscodium  
Denise: https://github.com/piciji/denise  
Vice: https://vice-emu.sourceforge.io/
